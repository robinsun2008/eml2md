# 第一章 文档格式与转换

离线环境下的文档转换，核心在于**依赖自包含**与*零联网调用*。

## 1.1 常见格式

* EPUB：本质是 ZIP 容器内的 XHTML
* MOBI：Kindle 旧格式，基于 PalmDOC 记录结构
* PDF：分文字层与扫描件两类

## 1.2 转换优先级

| 格式 | 首选引擎 | 备注 |
| --- | --- | --- |
| EPUB | XHTML 解析 | 保留标题层级 |
| MOBI | 解包后解析 | 需先还原 HTML |

> 转换的目标是保留结构，而不只是抽取文字。
